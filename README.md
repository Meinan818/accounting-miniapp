## 体验聊天与非AI入口

1. 聊天输入“今天吃面25，买咖啡18”，再说“咖啡改成16”，确认两笔后入账41元。
2. 明细点击整条账单进入编辑面板，改金额后保存；回聊天问“本月餐饮多少”，汇总使用最新已保存记录，不统计草稿。
3. 首页/聊天/明细点“手动记一笔”，直接填表保存；同样可在明细修改，无须AI或外部密钥。

新金额按整数分校验和计算；整组写入前全部检查，单次本地账单写入成功后才标为已记账。写入失败保留草稿/表单；损坏旧数据不自动覆盖。同组有稳定标识防止双击/文字确认/刷新后重复入账；编辑不改变原账单ID和组标识。浏览器本地数据不提供跨设备或数据库级多用户事务保证。

### 单笔删除（本地演示）

明细点击整条账单→编辑面板底部“删除这笔账单”→核对事项/金额/日期→“确认删除”；“返回编辑”保留尚未保存的输入，不写入。建议先用一笔测试账单体验，确认后该笔会从当前浏览器的账本与汇总中移除。

采用同一存储内的本地逻辑删除标记，保留原记录/组标识防止旧草稿重新入账，并非彻底擦除历史；暂不提供恢复入口。聊天卡片显示删除状态且不计入合计。没有后端、回收站或跨设备保证；保存失败时保留原账单并提示重试。

手动保存成功后会跳到对应月份，并自动定位、标记“刚刚记下”的账单，不改变日期排序；删除成功会显示可见提示。若开发旧页面提示数据模块版本过旧，先保存或取消当前编辑再刷新页面，不要清除浏览器存储。

### 月度统计（本地演示）

首页底部“统计”进入收支统计页，支持月份切换、月收入/支出/结余/有效笔数，切换收入/支出查看分类金额、占比和笔数；“查看明细”打开所选月份。金额来自同一本账，新增/修改/删除后同步；未确认草稿和逻辑删除项不统计，已有未来日期按所属月份统计，不改日期排序。分类占比显示一位小数，四舍五入后合计可能略有差异。空月份为零/空状态，存储损坏时显示错误而不是假零，不覆盖原内容。

统计仍是当前浏览器的本地演示，没有后端接口或确认率/AI准确率等质量指标。本轮60项Node测试通过，完整验证见LOG最新记录。

### 聊天历史与恢复提示

聊天先显示最近40条消息，可点“查看更早对话”逐批查看；这是显示窗口，不会删除或截断历史。更早的未完成草稿会单独显示，仍可继续补充或确认。本月查询和统计页复用同一账本计算口径。

浏览器对话保存失败时可点“重试对话保存”。旧历史读取失败时会保护原内容；“重新读取旧对话”仅在本页没有新增内容时恢复合法历史，已有新消息时会阻止覆盖并提示先备份。不要为处理错误清除浏览器数据。当前仍为本地演示，已增加已知旧快照覆盖保护；全量保存成本和真正同时写入的竞争仍是限制。

同一浏览器另一页更新对话时，旧页面会提示并暂停对话写入，不自动覆盖或合并。没有未保存内容时可点“重新读取最新对话”；本页已有未保存消息/草稿时会拒绝重读，请保留本页内容，不要刷新或清除存储。提示期间明确确认的账单仍以明细中的实际保存结果为准，对话保存与账单保存是两件事。此保护不是跨页面原子锁。

聊天可直接问“本月总支出”“本月总收入”或“总支出”，会走汇总查询，不生成记账草稿。当前只支持本月；未指定月份会说明范围，全部历史总额暂不支持。旧版误生成的待补充卡片不会自动删除，可由你点击“取消这组”，只取消草稿，不删除账单。

### 我的本地账本页

/profile展示当前有效账单笔数、本月收支及明细/统计/聊天入口，读取同一本账；未确认或已删除项不计入。坏数据不会显示假零或清空原存储，可显式重读。可编辑本地昵称（1–20字）、签名（最多60字）与3种预置SVG头像或自定义照片，独立保存到miaoji_local_profile_v1，不改变账本/对话；失败不报成功，旧快照发现变化时暂停写入。照片支持10MB以内的JPG/PNG/WebP，本机居中裁剪为256px JPEG，保存前可取消，原照片不修改、不上传服务器。没有正式账号、服务端头像上传、注销、云同步或清空功能，版本来自前端包信息。正式版账号资料及身份校验验收见PROJECT_PLAN.md。
