# 接手提示词（复制粘贴用）

> 换班时，把对应那一段**整段复制**，贴给另一个 AI 的对话框。
> 不用改任何字——两个 AI 会自己读文件、自己判断该不该开工。

---

## 一、贴给 Claude 的

```
你接手「智账 (ZhiZhang)」这个项目（记账 Web 应用，Vue 3 + Vite + Tailwind + Supabase）。
先别动任何文件，按下面顺序做：

1. 完整读仓库根目录的 AGENTS.md（这是唯一权威文档，尤其第 0 节「多 AI 协同开发协议」）。
   注意：同目录的 CLAUDE.md 只是指向 AGENTS.md 的指针，里面没有规则。
2. 读 .workbuddy/coop/state.json，看 holder 是谁。
3. 读 .workbuddy/coop/BATON.md 最后两条记录，了解上一个 AI 干了什么、留下什么。
4. 跑 git log --oneline -5、git status --short、git branch --show-current，确认现场。

然后向我汇报（只汇报，不要改代码）：
- 现在轮值锁在谁手上？我（Claude）现在能不能开工？
- 当前分支是什么？有没有未提交 / 未推送的东西？
- 上一个 AI 留下的、需要我接着做的事是什么？
- 你建议我第一步做什么？

汇报末尾必须按 AGENTS.md §0.6 的格式给出「—— 下一步 ——」区块，告诉我该去找谁。

注意：你的分工是「架构设计、数据库结构、API 设计、视觉规范、代码审查、拆任务」，不直接写实现代码。
另外这个项目有一条硬规矩：改文档时不要往 CLAUDE.md 里抄规则，规则只写在 AGENTS.md。
```

## 四、忘词了怎么办

不用回来翻这个文件。**直接跟当前那个 AI 说：**

```
看一下 AGENTS.md 第 0 节，告诉我现在该找谁、把哪段提示词贴过去。
```

它会读规则、读轮值锁，然后告诉你答案。
