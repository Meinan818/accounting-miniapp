## 遇到的问题

### ⚠️ git index.lock 文件锁定

- **问题**：首次 `git add` 时遇到 `.git/index.lock` 文件存在，导致无法操作
- **原因**：上一次 git 进程未正常退出
- **解决**：请求文件删除权限后移除 lock 文件，后续操作正常

### ℹ️ 24 个文件的行尾符变化

- **现象**：`git status` 显示 24 个 `frontend/` 下的文件被标记为修改（M）
- **原因**：只是 CRLF vs LF 行尾符差异，不是实质性代码改动
- **处理**：不影响代码审查，已在审查报告中说明
