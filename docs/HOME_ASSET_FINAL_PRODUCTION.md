## 二、重复素材检查

### `calendar-frame` 和 `calendar-paper`

结论：第一版只做 `calendar-frame.png`，纸张底色由 CSS 完成。

原因：

- 日历内容必须保持可点击和可更新，不能用一张完整日历图片。
- 纸张颜色和纹理可以先由 CSS 控制。
- 只有原稿纸张纹理非常复杂、CSS 无法还原时，才在后续单独增加 `calendar-paper.png`。
- 不要同时制作 `calendar-frame.png`、`calendar-paper.png`、`calendar-background.png` 三套近似素材。

### `bottom-wave` 和 `bottom-scene`

结论：只做 `bottom-wave.png`，猫咪、熊、植物和叶片仍按独立素材处理。

原因：

- `bottom-wave` 负责背景轮廓。
- 猫咪和熊需要独立层级，后续才能调整大小和位置。
- 不要生成 `bottom-scene.png` 这种包含全部角色的大组合图，否则后续无法独立定位。

### `plus-button`、`plus-glow`、`plus-rays`

结论：第一版只保留一个 `plus-button.png`，射线可以合并进去；以后需要动效时再拆。

原因：

- `plus-glow.png` 当前是临时复合素材。
- 不要同时生成 `plus-glow`、`plus-button`、`plus-rays` 三个重叠文件。
- 如果后续要让射线单独呼吸或转动，再新增 `plus-rays.svg` 或 `plus-rays.png`。

### `calendar-clip`

结论：只做一张 `calendar-clip.png`，右边用 CSS 镜像。

原因：

- 原稿左右夹子基本对称。
- 单独做左右两份容易产生细微不一致和重复维护。

## 五、最终统一规范

所有第一批和第二批插画素材：

- 透明背景
- 深棕色统一描边
- 线宽统一
- 圆润造型
- 手账风
- 水彩/蜡笔质感
- 柔和光影
- 不含文字
- 不含数字
- 不含 UI 截图
- 四周保留约 8%～12% 透明安全留白
- 边缘不要用白色底代替透明
