# UI 设计说明

## 设计原则

### 1. 简洁高效
- 快速记账：首页点击「+」直接进入记账页
- 最少步骤：3步完成记账（金额→分类→确认）
- 信息层级清晰：突出核心数据（金额、日期、分类）

### 2. 视觉统一
- 色彩体系统一：主题色、收入色、支出色保持一致
- 图标风格统一：使用同一套图标库
- 间距规范：遵循 8px 栅格系统

### 3. 反馈及时
- 操作反馈：点击、滑动、提交都有视觉反馈
- 状态提示：加载、成功、失败都有明确提示
- 手势引导：首次使用时提供操作引导


```
│  票据: [+拍照]              │  票据上传
├─────────────────────────────┤
```

**组件说明**:

- 点击票据打开相机/相册
- 点击确定提交数据

**验证规则**:
- 金额必须大于 0
- 必须选择分类
- 日期不能超过今天

## 组件设计

### 1. 账单卡片 (RecordCard)

**样式**:
```vue
<view class="record-card">
  <view class="category-icon" :style="{ background: categoryColor }">
    {{ categoryIcon }}
  </view>
  <view class="record-info">
    <view class="category-name">{{ categoryName }}</view>
    <view class="record-time">{{ time }} {{ remark }}</view>
  </view>
  <view class="record-amount" :class="type">
    {{ type === 'expense' ? '-' : '+' }}{{ amount }}
  </view>
</view>
```

**尺寸**:
- 高度: 80rpx
- 左右边距: 30rpx
- 上下边距: 20rpx
- 圆角: 16rpx

### 2. 分类选择器 (CategoryPicker)

**样式**:
```vue
<view class="category-picker">
  <view 
    v-for="category in categories" 
    :key="category.id"
    class="category-item"
    :class="{ active: selectedId === category.id }"
    @click="selectCategory(category)"
  >
    <view class="category-icon" :style="{ background: category.color }">
      {{ category.icon }}
    </view>
    <text class="category-name">{{ category.name }}</text>
  </view>
</view>
```

**布局**:
- 每行 4 个
- 正方形按钮
- 选中时有边框高亮

## 动画效果

### 1. 页面转场
- 左右切换：`slide-left` / `slide-right`
- 上下切换：`slide-up` / `slide-down`
- 淡入淡出：`fade-in` / `fade-out`

### 2. 列表动画
- 新增项：从底部滑入
- 删除项：向左滑出并淡出
- 加载更多：骨架屏占位

### 3. 按钮反馈
- 点击时：缩小 0.95
- 弹起时：恢复 1.0
- 过渡时间：150ms

## 响应式设计

### 适配方案
- 使用 `rpx` 单位（750rpx = 屏幕宽度）
- 关键元素使用固定 `px`（如边框 1px）
- 字体大小：
  - 主标题：36rpx
  - 正文：28rpx
  - 辅助文字：24rpx
  - 小字：20rpx

### 安全区域
- 顶部状态栏：使用 `uni.getSystemInfoSync()` 获取高度
- 底部安全区域：iPhone X 等设备适配
