# 智账首页素材规格表（Step 3）

> 本文件是首页视觉重构前的素材准备规范。
> 本阶段不移动现有素材、不修改首页组件、不修改业务逻辑、不生成图片、不引入字体。

## 一、统一原则

### 图片素材和 CSS 的边界

优先使用 **CSS / HTML**：

- 普通日期状态
- 今天日期状态
- 选中日期状态
- 日期文字
- 星期标题
- 月份切换按钮
- 导航文字
- 导航激活状态
- 卡片布局
- 阴影
- 圆角
- 间距

优先使用 **独立透明 PNG / SVG**：

- 小黄鸡
- 标题刷色
- 日历夹子
- 日历纸张装饰
- 猫、熊、植物、叶片
- 底部黄色波浪
- 四个导航插画图标
- 中央 + 按钮装饰
- 其他具有明显手绘插画边缘的装饰

### 所有插画素材统一规范

所有插画素材必须：

- 透明背景
- 深棕色统一描边
- 统一线宽
- 圆润造型
- 手账风格
- 水彩或蜡笔质感
- 柔和光影
- 不包含文字
- 不包含数字
- 不包含按钮
- 不包含完整 UI 截图
- 导出时保留边缘透明像素

### 默认预览尺寸和导出尺寸

- 预览尺寸：以最终在 390×844 视口中的逻辑尺寸为准。
- 建议导出尺寸：优先 2x 或 3x；复杂手绘插画建议至少 1024px。
- 安全留白：所有角色和装饰四周保留约 8%～12% 透明安全区。
- 边缘透明要求：不要用白色底色代替透明背景；不要裁掉手绘边缘的半透明像素。

## 四、目录规划

当前阶段只建立目录占位，不移动已有文件，避免破坏现有 import：

```text
frontend/src/assets/design/
├─ mascot/
├─ calendar/
├─ decoration/
├─ navigation/
├─ common/
└─ source/
```

现有根目录下文件暂时保持原位。后续真正迁移时，必须同步修改：

- `Home.vue`
- `CalendarCard.vue`
- `BottomNav.vue`

但本阶段不允许修改这三个文件，所以本阶段不执行迁移。
